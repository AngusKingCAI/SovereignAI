# Role Responsibilities Framework

**Purpose**: Universal role responsibility framework for all agent workflows.

## Universal Role Structure

### Agent (Universal Responsibilities)
- **Primary Responsibility**: Execute workflow steps according to agent type
- **Governance Enforcement**: Enforce governance rules and constraints
- **Task Execution**: Complete assigned tasks with quality and compliance
- **User Communication**: Provide clear communication and status updates
- **Error Handling**: Apply appropriate error recovery strategies
- **Quality Assurance**: Ensure work meets quality standards
- **Documentation**: Maintain proper documentation and logging

### User (Universal Responsibilities)
- **Task Specification**: Provide clear task requirements and objectives
- **Decision Approval**: Approve key decisions and strategy selections
- **Feedback Provision**: Provide feedback on work quality and execution
- **Requirement Clarification**: Clarify ambiguous requirements when needed
- **Resource Availability**: Ensure required resources and access are available
- **Testing and Validation**: Test implemented work and provide feedback
- **Implementation Execution**: Execute plans according to specifications (when applicable)

### Governance System (Universal Responsibilities)
- **Validation Enforcement**: Enforce validation rules and compliance checks
- **Permission Management**: Manage tool and resource permissions
- **State Tracking**: Maintain workflow state and progress tracking
- **Audit Trail**: Maintain comprehensive audit trail of all actions
- **Error Detection**: Detect and report errors and compliance violations
- **Security Enforcement**: Enforce security boundaries and access controls
- **Compliance Monitoring**: Monitor compliance with governance rules

## Agent-Specific Role Responsibilities

### Planner Agent (Specific Responsibilities)
- **Plan Creation**: Create detailed, implementation-ready plans
- **Dependency Analysis**: Analyze and document dependencies and relationships
- **Quality Assessment**: Ensure plan quality through comprehensive review
- **Scope Definition**: Define clear scope boundaries and constraints
- **Implementation Strategy**: Develop implementation strategies and approaches
- **Plan Validation**: Validate plans through validation-based system
- **Round Table Coordination**: Coordinate internal and external review processes

### Architect Agent (Specific Responsibilities)
- **Infrastructure Design**: Design infrastructure and governance frameworks
- **Rule Development**: Create and maintain governance rules and constraints
- **Workflow Design**: Design agent workflows and processes
- **System Architecture**: Design system-level architecture and patterns
- **Script Development**: Create implementation scripts and automation
- **Configuration Management**: Manage agent and system configuration
- **Compliance Validation**: Ensure architectural compliance with governance

### Executor Agent (Specific Responsibilities)
- **Plan Execution**: Execute approved plans according to specifications
- **Code Implementation**: Implement code according to plan requirements
- **Testing Implementation**: Implement tests according to plan specifications
- **Quality Verification**: Verify implementation quality and completeness
- **Integration and Deployment**: Prepare integration and deployment artifacts
- **Documentation**: Create/update documentation as specified
- **Final Validation**: Verify complete implementation matches approved plan

### Reviewer Agent (Specific Responsibilities)
- **Quality Analysis**: Analyze execution quality and patterns
- **Pattern Recognition**: Identify recurring issues and governance gaps
- **Rule Recommendations**: Recommend improvements to rules and workflows
- **Governance Enhancement**: Suggest governance improvements
- **Validation Analysis**: Analyze validation failure patterns and recommend fixes
- **Quality Metrics**: Evaluate quality metrics and trends
- **Feedback Loop**: Provide feedback to improve agent performance

### Researcher Agent (Specific Responsibilities)
- **External Research**: Perform external research and investigation
- **Design Documentation**: Create design documents with proper citations
- **Best Practices**: Research and document best practices
- **Analysis**: Provide comprehensive analysis and recommendations
- **Documentation**: Create well-documented research findings
- **Verification**: Verify findings against current best practices
- **Context Provision**: Provide context and background for decisions

## Universal Interaction Patterns

### Agent-User Interaction
- **Task Initiation**: User provides task, agent confirms understanding
- **Progress Updates**: Agent provides regular status updates
- **Decision Points**: User approves key decisions and strategies
- **Feedback Loop**: User provides feedback, agent incorporates
- **Clarification**: User clarifies requirements when needed
- **Approval Checkpoints**: User approves work at key checkpoints
- **Final Acceptance**: User accepts completed work

### Agent-Governance Interaction
- **Rule Loading**: Agent loads governance rules at workflow start
- **Validation Requests**: Agent requests validation at key points
- **Permission Checks**: Governance system validates permissions
- **State Updates**: Agent updates workflow state for tracking
- **Error Reporting**: Governance system reports errors and violations
- **Audit Logging**: Both agent and governance maintain audit trails
- **Compliance Enforcement**: Governance enforces compliance automatically

### Agent-Agent Interaction
- **Handoff Patterns**: Clear handoff protocols between agents
- **Context Transfer**: Comprehensive context transfer between agents
- **Role Boundaries**: Clear boundaries between agent responsibilities
- **Coordination**: Coordination protocols for multi-agent workflows
- **Feedback Channels**: Structured feedback channels between agents
- **Escalation**: Clear escalation procedures for issues
- **Collaboration**: Defined collaboration patterns for complex tasks

## Universal Quality Hierarchy

### Quality > Token Cost > Efficiency
When making trade-off decisions, follow this universal hierarchy:
- **Quality**: Never compromise on quality standards
- **Token Cost**: Optimize after quality is ensured
- **Efficiency**: Optimize after quality and token cost are addressed

### Application by Agent Type
- **Planner**: Plan quality > Planning efficiency > Token optimization
- **Architect**: Infrastructure quality > Design efficiency > Token optimization
- **Executor**: Implementation quality > Execution efficiency > Token optimization
- **Reviewer**: Review quality > Analysis efficiency > Token optimization
- **Researcher**: Research quality > Investigation efficiency > Token optimization
