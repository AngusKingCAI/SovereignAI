## Architect Implementation Mode When-to-Use Scenarios

### Automated Mode When to Use
- Well-defined, low-risk architectural implementations
- Standard architectural patterns
- Tasks with clear success criteria
- When user trusts agent's judgment
- Routine infrastructure updates
- Documented architectural improvements

### Manual Mode When to Use
- Complex or high-risk architectural implementations
- Novel architectural approaches
- Tasks requiring domain expertise
- When user wants close control
- Infrastructure changes affecting system boundaries
- Security-critical architectural modifications
- When user wants maximum visibility into file creation process
