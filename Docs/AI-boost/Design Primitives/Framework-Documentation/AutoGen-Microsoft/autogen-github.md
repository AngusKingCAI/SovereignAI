## Repository Overview

This is the official AutoGen repository from Microsoft. The repository contains:

- **Python implementation**: `python/` - Main Python SDK
- **.NET implementation**: `dotnet/` - .NET SDK
- **Documentation**: `docs/` - Comprehensive documentation
- **Protocol buffers**: `protos/` - Protocol definitions
- **Azure pipelines**: `.azure/pipelines/` - CI/CD configurations
- **Dev containers**: `.devcontainer/` - Development container configurations
