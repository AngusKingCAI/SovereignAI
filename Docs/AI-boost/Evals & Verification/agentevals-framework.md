# AgentEvals Framework

**Source:** https://github.com/agentevals-dev/agentevals

## Overview
AgentEvals is an evaluation framework for AI agents. The repository contains tools and infrastructure for evaluating agent performance and behavior.

## Repository Structure
- `.claude/skills` - Claude skills configuration
- `.github` - GitHub workflows and configuration
- `charts/agentevals` - Helm charts for deployment
- `docs` - Documentation
- `examples` - Example implementations
- `packages/evaluator-sdk-py` - Python SDK for evaluator
- `samples` - Sample configurations
- `src/agentevals` - Source code
- `tests` - Test suite
- `ui` - User interface components

## Key Features
- Comprehensive evaluation framework for AI agents
- Python SDK for integration
- Deployment charts for production use
- Extensive documentation and examples
- Testing infrastructure

## Usage
This framework provides tools for evaluating agent performance, behavior, and reliability. It includes SDKs for Python, deployment configurations, and a user interface for monitoring evaluation results.

For detailed usage instructions, refer to the repository documentation and examples directory.
